# Changelog

## 0.1.0

- Initial `KHR_interactivity` support for Three.js and Needle Engine.
- Browser-compatible TypeScript declarations.
- Automatic graph startup, graph validation, and `KHR_animation_pointer` support.
- Desktop selection and hover, plus Needle XR controller and hand input.
- Scene, material, animation, and camera bindings, including node camera references.
- Synchronized graph and animation timing, with reverse playback and `stopAt` completion.
